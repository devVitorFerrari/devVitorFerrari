## Projeto em destaque

### [Controle de Estoque](https://github.com/devVitorFerrari/controle-estoque)

Aplicação para cadastrar produtos, registrar entradas e saídas, consultar o histórico e identificar itens abaixo do estoque mínimo.

Uma regra do projeto é impedir saídas maiores que o saldo disponível. No Oracle, a validação do saldo, a atualização da quantidade e o registro da movimentação fazem parte da mesma transação.

**Tecnologias do projeto:** React, TypeScript, ASP.NET Core (.NET 8) e Oracle.
